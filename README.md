📊 Expense Tracker Web App

A modern, responsive Expense Tracker built using HTML, CSS, and JavaScript, featuring login system, category-based tracking, monthly filter, animated UI, pie-chart visualization, edit/delete options, and PDF export.

✅ Features

💰 1. Income & Expense Management

Add transactions with:

✅ Description

✅ Category (Food, Travel, Bills, Shopping, Others)

✅ Positive/Negative Amount

Edit any transaction.

Delete transactions.

All data saved in localStorage.

📅 2. Monthly Filter

Filter all transactions by selected month.

Automatically updates:

✅ Summary

✅ Chart

✅ Transaction history

📊 3. Pie Chart (Income vs Expense)

Built using Chart.js

Auto-updates when:

Adding transactions

Editing/deleting transactions

Applying monthly filter

📥 4. PDF Export

Generates downloadable PDF report of all transactions.

Uses jsPDF.
